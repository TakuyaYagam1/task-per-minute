# Тестовый стенд

Данные и сервисы для проверки турниров одним человеком. При запуске тестового
Compose импортируются 54 задачи и создаются 16 подтвержденных аккаунтов
`demo01`-`demo16`. Боты занимают остальные места в турнире на 8 или 16 игроков.

## Что проверяем

- Регистрацию, подтверждение участия и готовность игроков.
- Swiss, Golden, драфт и плей-офф с сериями BO1 и BO3.
- Победу и поражение игрока, переходы между стадиями и итоговый результат.
- Паузу ботов, переподключение, перезапуск и повторный турнир без очистки БД.
- Доступ к панели только для тестировщика и выдачу ответа только на его задачу.

## Как пользоваться

Для локального запуска укажи ID своего подтвержденного аккаунта в
`TEST_BOTS_CONTROLLER_PLAYER_ID` в локальном файле `.env.test-bots.local`:

```sh
docker compose --env-file .env.local --env-file .env.test-bots.local \
  -f deployment/docker/docker-compose.local.test.yml up -d --build
```

В админке создай турнир на 8 или 16 игроков с тестовым каталогом и нулевыми
резервами. Со своего аккаунта вступи в турнир и нажми "Заполнить ботами"
в панели "Тестирование". Пары, волны и переходы стадий запускаются вручную
из отдельной вкладки админки.

Для сценария Golden выбери "Пройти Golden" до начала Swiss, категории Crypto
для Swiss и полуфиналов и "Подставить пары сценария" в каждом раунде.
Проиграй первый раунд и выиграй остальные. Финал проходит в BO3.

Пароли и тестовые ответы хранятся в закрытых Docker volumes. Сохраняй их
вместе с тестовой БД. Для нового прогона создавай новый турнир.
